# ClipB v0.8.4

ClipB is a local-first desktop clipboard manager for macOS and Windows.

## Highlights

- Corrected app and updater version metadata. The previous v0.8.3 release included the latest fixes but still identified itself as 0.8.2, preventing existing 0.8.2 installations from detecting a newer update.
- Background clipboard checks use a native timer, with protection against hidden-window suspension.
- Quick Copy refreshes when background capture saves a clip.
- Quick Copy supports macOS desktops and fullscreen spaces and opens on the display under the pointer.
- Clipboard capture waits for saved privacy settings to load before it starts.

## Release Reliability

- CI checks that all app version files agree.
- Release builds stop if the Git tag does not match the app version.
- Apple Silicon, Universal macOS, and Windows builds use the same validated source commit.

## Downloads

- **Windows x64:** `.exe` installer.
- **macOS Apple Silicon:** `.dmg` for M-series Macs.
- **macOS Universal:** `.dmg` for Apple Silicon and Intel Macs.

Existing installations with the updater can use **Settings > Check for updates** once this release is published. Linux builds are not included yet.

## Security and Privacy

These builds are not yet signed with an Apple Developer ID or Windows code-signing certificate. macOS builds are not notarized. Operating-system security warnings may still appear; the signatures included with updater artifacts verify updates and do not replace platform code signing.

ClipB stores clipboard history locally. No account, telemetry, or cloud sync is required or added by this release.
